## 🚀 Projects

### Credibilistic Portfolio Optimisation
Multi-objective genetic algorithm (NSGA-II) for portfolio selection under fuzzy uncertainty, replicating and extending Mandal, Thakur & Mittal (2024). Implements 4 objectives — credibilistic mean, semivariance/MASD/CVaR, skewness, semikurtosis — computed in closed form from Credibilistic Triangular Fuzzy Numbers fitted to NSE & NYSE returns.

- Caught and fixed 3 bugs in the published paper's formulas
- Extended Model III (CVaR) with Entropic VaR (EVaR) — achieved +8.2% cumulative return improvement on NSE test data
- Stack: Python · NSGA-II · scipy · pandas · yfinance

### MunoAI Lead Finder
Automated B2B lead sourcing pipeline for Mindtraqk (AI workforce intelligence SaaS). Queries Apollo API, deduplicates across runs, logs to Google Sheets, and refines search parameters via a feedback loop.

- Stack: Python · Apollo API · Google Sheets API · gspread

- Stack: HTML · CSS · JavaScript
