## 🚀 Projects

### SLM Reasoning via Reinforcement Learning
Fine-tuned **Phi-3-Mini (3.8B)** for multi-step reasoning using a three-stage pipeline: baseline evaluation → SFT warmup on OpenMathInstruct-2 → **GRPO** (Group Relative Policy Optimization — the same RL technique behind DeepSeek-R1). Achieved **79.5% on GSM8K** at baseline after fixing truncation and answer-extraction bugs; fine-tuning targets +5pp on GSM8K, MMLU, and StrategyQA. Training via LoRA on H100.

- Ennovate-X Hackathon — Problem Statement 06
- Stack: Python · PyTorch · TRL · PEFT · LoRA · lm-evaluation-harness · Transformers

### Credibilistic Portfolio Optimisation
Multi-objective genetic algorithm (NSGA-II) for portfolio selection under fuzzy uncertainty, replicating and extending Mandal, Thakur & Mittal (2024). Implements 4 objectives — credibilistic mean, semivariance/MASD/CVaR, skewness, semikurtosis — in closed form from Credibilistic Triangular Fuzzy Numbers fitted to NSE & NYSE returns.

- Caught and fixed 3 bugs in the published paper's formulas
- Extended baseline with Entropic VaR (EVaR) — +8.2% cumulative return on NSE test data
- Stack: Python · NSGA-II · scipy · pandas · yfinance

### IIT Mandi 3D Campus Map
Interactive 3D map of IIT Mandi campus built with React, rendering full campus GLB models in the browser. Lets students and visitors explore the campus spatially.

- Stack: React · Three.js · GLB / 3D modelling

### MunoAI Lead Finder
Automated B2B lead sourcing pipeline for Mindtraqk (AI workforce intelligence SaaS). Queries Apollo API, deduplicates across runs, logs to Google Sheets, and refines search parameters via a feedback loop.

- Stack: Python · Apollo API · Google Sheets API · gspread
